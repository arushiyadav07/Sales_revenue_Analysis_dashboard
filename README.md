# Sales & Revenue Analysis Dashboard

## Project Overview
This project is a beginner-level Power BI dashboard created using Excel data. It analyzes sales, profit, and product performance through interactive visualizations.

## Features
- Sales by Product
- Profit by Category
- Sales Trend Analysis
- Interactive Charts

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Project Files
- Sales-Revenue-Analysis-Dashboard.pbix
- Sales Dataset.xlsx
